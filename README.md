# Dujohn Mobile Essentials | DME

Dujohn Mobile Essentials (DME) is a Jamaica-based online mobile essentials and accessories brand offering quality mobile products, accessories, and professional device repair services.

This repository contains the source code for the official DME e-commerce website.

---

## 🚧 Project Status

**Status:** In Development

DME is being built from the ground up as a production-oriented e-commerce platform.

The project will initially focus on:

* Mobile accessories and essentials
* Online product browsing
* Customer accounts
* Shopping cart and checkout
* Device repair services
* Jamaica-wide delivery
* Online payments

Additional functionality will be introduced as the business grows.

## 🔐 Security

Security will be treated as a core part of the application.

Planned security measures include:

* Password hashing
* Secure authentication
* Authorization
* Environment variables for secrets
* Input validation
* Database security
* Secure payment handling
* Production HTTPS

Sensitive credentials and environment configuration will never be committed to the repository.
